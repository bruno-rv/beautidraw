# Examples

Drop your `.excalidraw` presentation files here. This is ticket 01 on the map
(`docs/design-notes/issues/01-example-excalidraw-files.md`) — the hardest blocker
in the effort. The visual system is clean-room: palette, typography, slide anatomy
and layout rules get derived from these files and nothing else.

For each file you add, note below:

| File | What it is | Imitate it, or just representative? |
|------|------------|--------------------------------------|
|      |            |                                      |

Flag any file that is a single dense diagram rather than a multi-frame
presentation, so it isn't mistaken for deck-layout evidence.
